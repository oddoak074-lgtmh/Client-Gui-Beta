# Zhwii Client (Forge 1.8.9)

Client-side mod: HUD widgets (FPS, CPS, Ping, Coordinates, Combo, Potion Effects,
Keystrokes, Armor Status, Clock, Biome, Server, Uptime), Auto Sprint, a settings menu
and a drag-and-drop HUD editor.

- Open the menu: **Right Shift** (rebind in Controls).
- Config file: `config/zhwiiclient.cfg`.
- Build (JDK 8): `gradle setupDecompWorkspace` then `gradle build` - jar in `build/libs/`.
